## 2. 四轮借鉴总评（存照）

- **softkit-core**（libs 分层库）：可借面宽——六轮产出结项切片 ×5（health-probe / pagination-contract / correlation / error-contract / pagination-coverage）+ 成文纪律 ×1（tooling §4.9）+ 挂账多段；方法论"借形不借身"全程零反例。
- **brocoders/nestjs-boilerplate**（经典时代应用级 boilerplate）：可借面窄——其立身之本（自研 auth 流程完整度）已被 better-auth 整体接管且我方装配深度反超（组织 RBAC/暂停 fail-closed/服务端编排网关）；双 ORM/flat 分层/0 单测三路线冲突项全部否决留档。**净产出 = 一条半反照式发现**（V1/V3 由它的对照照出，非它的方案本身），印证借鉴线老规矩：被评价仓库的价值上限是"照出我方盲区"。
- **ixartz/SaaS-Boilerplate**（indie Next.js 全栈营销壳·7.5k★·MIT·月更兑现）：与 brocoders 同构的可借面窄——其宣称的 SaaS 核心机制（认证/多租户/RBAC）全托管在 Clerk 云、支付/CRUD 示例/暗色模式/事务邮件锁付费档，免费版仓库（155 文件·todo 单表 26 行·integration 测试空·e2e 仅 3 文件）业务工程实践趋零。**否决留档 ×4**：Clerk 托管认证/租户/RBAC（违 BA 自持裁 + PIPL 驻留）；构建期自动迁移 `build=run-s db:migrate build:next`（违高危#1 迁移纪律·多实例竞跑 DDL）；Crowdin 机翻流水线（本仓 i18n 资产随镜像走已定案）；Next.js 全栈单体形态（与本仓 API/SPA 分体 + core 宪法冲突——依本轮人定向口径「不换栈不换架构」直接出局）。**净产出 = 运维可观测面七候选（X1–X7·live main 复验增补 X6/X7）**：其立身之本（外围服务集成最宽）恰是本仓薄面（错误监控/合成拨测/键级 i18n 闸），再证「照出我方盲区」老规矩。
- **ueberdosis/tiptap**（headless 富文本编辑框架·38.8k★·MIT·2018 起·日更级活跃）：性质与前轮不同——**非 boilerplate 而是垂直领域基础库**，评价维度从「照盲区」换为「选型资格 + 架构旁证」。**选型资格**（登记 T1·触发制）：v3 起 60+ 包全量 MIT（原 Pro 扩展 drag-handle/unique-id/bubble-menu 等已开源·逐包 license 实证）+ 协作后端 Hocuspocus 亦开源可自托管（Yjs CRDT·非绑云）——商业边界收缩到「卖托管运营（Tiptap Cloud/Content AI）+ 订阅制 Pro 扩展（评论/版本/AI）」，对本仓 PIPL 口径**存在合规可用路径**（core + 自托管 Hocuspocus·云与 Pro 不采）。**架构旁证 ×3（无行动·只存照）**：① headless core + react/vue 薄绑定包布局 = 我方 packages/core 框架无关 + 应用装配的成熟先例；② `@tiptap/pm` 伞包收敛 ProseMirror peer 版本防漂移 = 我方 libs/contracts zod 单版本同构；③ 编辑器运行时与 `static-renderer` 读写分离 = CQRS 读侧投影同构（ProseMirror 文档=事务流回放·与 ES 文化同频）。弱面如实：912 open issues、ProseMirror 重量/学习曲线、公开 CI 仅 3 workflow（build/notify/publish·测试收在 build 内·门禁可见度低于本仓）。**净产出 = T1 一行 + X5 二次印证**。
