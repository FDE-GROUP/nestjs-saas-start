- API 调用统一使用原生 `fetch` 并携带 `credentials: 'same-origin'`，所有请求头显式声明 `Accept: application/json`。
- 网络错误按状态码分类处理：5xx 视为「服务不可用」抛出或返回结构化错误对象，非 5xx 且非 ok 则解析 body 中的 `message` 字段回显给用户。
- 页面组件通过 `createFileRoute` 导出 `Route` 常量，并在 loader 中调用 `getSession()` 实现 deny-by-default 的鉴权守卫，未登录跳转 `/login`。
- Odoo 数据面的响应体一律通过 zod schema 进行运行时校验，解析失败即视为上游契约漂移并转为 UI 错误态，而非静默降级。
