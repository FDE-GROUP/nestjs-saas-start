- 跨层依赖通过 Symbol 常量（`AUTH_SESSION_STORE`、`AUTH_USER_STORE`、`MCP_ACCESS_TOKEN_STORE`、`AuthInstanceInjectKey`）作为 DI token 解耦，而非直接 import 具体类。
- 基础设施对领域的写入统一经 `domain/ports/*.port.ts` 定义的接口，禁止业务 handler 直接操作 MikroORM entity 或 session 表。
- Nest 服务构造注入一律使用值导入 + 显式 `@Inject(...)` 装饰器，避免 Biome autofix 将类型导入改写为 `import type` 导致 `design:paramtypes` 退化。
- 对外暴露的 HTTP 入口先经全局 `SessionGuard`（deny-by-default）再叠加 `CsrfOriginGuard`，公共路由通过 `@Public()` + `Reflector` 旁路。
- better-auth 的原生 API 在 `auth.implement.ts` 中以窄门面方法（`getSession`、`createOrganization`、`signUpEmail` 等）重新导出，屏蔽内部实现细节。
- 环境敏感开关（如 `emailAndPassword.enabled`、`SESSION_RECLAIM_ENABLED`、`isSealedOrgHttpPath`）集中在 `CreateAuth` 与 bootstrap 层判定，并以 `Logger.warn` 输出诊断信息而非静默降级。
