- 核心能力以端口 token（如 `SESSION_READER`、`TENANT_SCOPE_RESOLVER`）定义于 `@core/saas-kit`，应用侧通过 `{ provide, useClass }` 在模块中绑定实现，保持 core 与应用解耦。
- 所有 MikroORM 查询经 `mikro.fork()` 获取独立实体管理器，避免共享状态；当解析器本身处于隔离机制锚（ALS 绑定前）时显式传 `scoped: false` 并配合精确 `where` 条件绕过当前租户过滤。
- 对 Better Auth 等外部库的访问统一收敛在 `infrastructure/` 下的适配器类中，对外仅暴露标量视图（如 `SessionView`），不在业务逻辑中直接持有框架对象。
- 路径匹配采用段对齐算法（先剥 query/hash，再逐段比较），防止子串误撞，用于 auth bypass 与 surface 路径的快速短路。
