- 领域策略以纯函数 + discriminated union 返回裁决结果（如 `UploadVerdict = { ok: true } | { ok: false; reason }`），由 application 层映射为 HTTP 异常，避免领域层抛出框架异常。
- 基础设施适配器统一继承 `BaseStorageProvider`，仅实现抽象方法（uploadFile/uploadFileFromStream/deleteFile/getFileUrl/getDefaultPublicUrl），共享的临时文件 IO、ETag 归一、key 生成下沉基类。
- 外部依赖通过 `StorageModule.register()` 的 `useFactory` + `Inject('STORAGE_PROVIDERS')` 令牌注入，运行时按 `storage.provider` 配置选择具体实现，未注册时回退到内置的 s3。
- HTTP 端点统一携带 `errorCode: ERROR_CODES.STORAGE_*` 字段，所有失败路径经 controller/service 两层归一后抛出 `BadRequestException`。
- Swagger 文档通过 `ApiExtraModels` + `@SerializeOptions({ schema })` 与 `@saas/contracts` 中的 zod schema 保持契约单源。
