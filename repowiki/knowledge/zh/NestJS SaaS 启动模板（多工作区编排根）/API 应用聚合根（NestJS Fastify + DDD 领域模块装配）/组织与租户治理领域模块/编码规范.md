- HTTP 端点通过 `@UseGuards(SessionGuard | PlatformOperatorGuard)` 逐路由选择鉴权墙，并在类或方法上配合 `@TenantIsolationExempt()` 豁免租户隔离（申请/审批无 active 租户）。
- 控制器方法使用 `@Impl(contract).input(schema).output(schema).meta(meta).handler(...)` 链式声明，入参/出参与 OpenAPI meta 单源来自 `@saas/api-contract`。
- 业务变更一律经 `CommandBus.execute(Command)` 派发至 `application/commands/handlers/*`，控制器不直接执行业务逻辑。
- 状态迁移统一走 `governedOrganizationTransition` 策略函数（approve/reject/suspend/resume/delete 共用），避免在各 handler 内重复分支。
- 仓储通过 `Symbol` token（如 `ORGANIZATION_GOVERNANCE_REPOSITORY`）在 DI 容器中注册，`organizations.module.ts` 用 `useClass` 或 `useExisting` 绑定 MikroORM 实现。
- 平台级仓储实现一律 `mikro.fork({ scoped: false })` 获取 EntityManager，显式绕过 ALS 租户过滤以保证跨租户语义。
