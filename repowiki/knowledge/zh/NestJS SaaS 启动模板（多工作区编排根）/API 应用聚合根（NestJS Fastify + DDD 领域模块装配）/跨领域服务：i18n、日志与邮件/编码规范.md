- Nest 模块以 `@Global()` 装饰器暴露给全应用（AppI18nModule、LoggerModule），而 MailerModule 保持局部作用域仅导出自身 Service。
- i18n 与邮件模板路径统一经由 `resolveI18nAssetsRoot()` / `resolveEmailsDir()` 单点解析，禁止直接使用 `dirname(import.meta.url)` 拼接相对路径。
- 邮件模板采用 MJML 文件 + `<lang>/emails.json` 键值对的双轨本地化模式，模板内使用 `{{'emails.<template>.<key>' | translate}}` 占位符配合正则替换。
- 日志输出根据 `NODE_ENV` 分支：生产走 pino/file 并保留 Nest Logger 默认 stdout，开发/测试走 pino-pretty 彩色控制台，避免双写。
