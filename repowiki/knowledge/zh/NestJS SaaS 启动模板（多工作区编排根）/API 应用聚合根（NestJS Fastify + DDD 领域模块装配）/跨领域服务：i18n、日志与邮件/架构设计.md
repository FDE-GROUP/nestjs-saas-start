模块由三个并列的 NestJS 子模块组成，彼此通过共享资产解析与依赖注入协作：
- `i18n/`：`AppI18nModule` 以 `@Global()` 暴露 `I18nModule.forRoot`，fallback 语言为 `zh`，使用 `AcceptLanguageResolver` 从 HTTP `accept-language` 头解析语言；`assets-root.ts` 是 i18n 与邮件模板资产的唯一解析入口，通过向上探测含 `zh/` 目录的方式兼容源码与产物两套布局，缺失时 fail-closed 抛错。
- `logger/`：`LoggerModule` 同样 `@Global()`，导出 `LoggerService`（继承 Nest `Logger`），根据 `NODE_ENV` 在 pino/file（生产，落 `LOG_FILE` 或 `logs/app.log`）与 pino-pretty（开发/测试）之间切换后端。
- `mailer/`：`MailerModule` 非全局，仅导出 `MailerService`；内部用 nodemailer 连接 SMTP，通过 mjml 渲染 `emails/*.mjml` 模板，正文/主题经 `I18nService` 按 `<lang>/emails.json` 翻译，模板变量占位符 `{{'emails.<template>.<key>' | translate}}` 由正则替换。
依赖方向：mailer → i18n.assets-root + I18nService；logger 独立；i18n 不反向依赖其他两个。
