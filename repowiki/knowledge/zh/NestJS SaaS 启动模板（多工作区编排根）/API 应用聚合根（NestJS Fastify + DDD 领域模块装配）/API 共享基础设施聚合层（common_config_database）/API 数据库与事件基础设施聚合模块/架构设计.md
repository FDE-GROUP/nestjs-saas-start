database.module.ts 作为 NestJS @Global Module 统一装配三个子层：
- mikro/ 提供 ORM 连接、懒建实例、全局行级租户/组织隔离 filter 及迁移实体集（mikro_orm_core）。
- eventing/ 基于同一 ORM 实现领域事件追加/回放（MikroEventStore）、DomainEventPublisher 三模路由（inproc/shadow/outbox）以及 outbox-relay 进程内中继（eventing_outbox）。
- 顶层 entity-column-law / table-ownership 等守卫与 seed 复用上述 ORM 能力（db_shared）。
所有消费者仅依赖 @core/saas-kit/shared-kernel/domain 中的 EVENT_STORE 与 DOMAIN_EVENT_PUBLISHER 端口，具体实现在此绑定；OutboxRelay 仅在 EVENT_PUBLISH_MODE=outbox 时启动定时器，保证 DB-free 装配不变量。
