- 所有对数据库的访问统一走 `MikroOrmService.fork()` 获取独立 EntityManager，禁止直接使用全局 `orm.em`。
- 对外数据访问契约以端口形式声明于 `@core/saas-kit/shared-kernel/domain/*.port`，本模块仅通过 `{ provide: PORT, useClass: Impl }` 装配具体实现。
- 事件追加采用影子追加语义：CRUD 作为唯一真相源，并发冲突由 DB 唯一键 fail-loud 抛错，不在应用层吞异常或重试覆盖。
- Outbox 投递遵循「事务内 claim（置 `dispatchedAt`）→ 提交后 publishAll」的两阶段顺序，消灭回滚下已下发事件的幻影事件。
- 租户隔离通过 MikroORM 全局 filter + ALS 派生参数注入，无 tenantId 上下文时恒真不筛（fail-open 豁免），有上下文时强制 `tenantId` 过滤并可叠加 `organizationId`。
