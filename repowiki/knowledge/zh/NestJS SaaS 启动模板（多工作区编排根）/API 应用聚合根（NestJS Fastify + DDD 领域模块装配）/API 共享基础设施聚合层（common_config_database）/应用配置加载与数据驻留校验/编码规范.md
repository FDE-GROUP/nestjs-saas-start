- 环境变量读取统一采用 `process.env.X || 'fallback'` 形式，并在 `default.ts` 中给出可运行的开发默认值，`development.ts` / `production.ts` 仅覆写差异项。
- CORS origin 白名单通过共享的 `parseCorsOrigins` 解析器处理，避免在三份 env 文件中硬编码 `origin: '*'`，生产端默认 fail-closed（空白名单）。
- SSO client 注册表走 JSON 字符串 env，由 `parseSsoClients` 用 Zod 校验，未配返回空数组（fail-closed），非法结构抛错（fail-loud）。
- 新增配置项需同步维护三处：`interfaces/config.interface.ts` 的类型定义、`config.service.ts` 的 typed getter、`config.module.ts` 中 `createSchemaForEnv` 的 Zod `baseSchema`。
- 可选/特性开关类配置（如 `EVENT_PUBLISH_MODE`、`SESSION_RECLAIM_ENABLED`、`ES_TRUTH_SOURCE_SUBSCRIPTIONS`）一律使用 `optional()` + 安全缺省，保证未注入时行为等价于关闭且不上 compose 编排。
- `data-residency.ts` 保持纯函数、无 Nest DI 副作用，通过 `ResidencyMode`（strict/warn）让调用方决定阻断还是告警，便于单元测试隔离。
