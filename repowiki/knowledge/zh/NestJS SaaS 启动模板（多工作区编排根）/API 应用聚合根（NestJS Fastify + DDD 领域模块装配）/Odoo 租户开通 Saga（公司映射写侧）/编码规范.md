- 跨层依赖通过 `Symbol` 常量（如 `ODOO_COMPANY_GATEWAY`）作为 DI token 暴露，并在 module providers 中以 `{ provide, useClass }` 形式绑定实现。
- 被注入类值导入时统一使用显式 `@Inject(Token)` 参数装饰器，避免 swc `design:paramtypes` 退化。
- 对外契约以 `interface` + `Symbol` 端口在 `infrastructure/` 下声明，具体 RPC 实现放在同目录另一个文件，保持 saga 零耦合。
- Saga 处理函数对非首次开通（`from !== PENDING || to !== ACTIVE`）以及已 `READY` 绑定行直接返回，确保 at-least-once 重投幂等。
- 未验证的 Odoo 深水区调用（l10n、管理员预配）以 `logger.warn` 占位跳过而非抛错，保留骨架可编译但明确标注联调边界。
