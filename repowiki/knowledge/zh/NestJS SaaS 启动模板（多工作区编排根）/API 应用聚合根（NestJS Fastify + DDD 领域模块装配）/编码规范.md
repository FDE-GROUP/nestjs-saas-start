- 领域模块统一采用 api/application/domain/infrastructure 四层目录划分，domain 层仅声明 ports/repositories，infrastructure 层提供适配器实现。
- 跨领域协作通过 domain/ports 接口解耦，调用方只依赖抽象而非具体仓储或服务。
- HTTP 端点通过 oRPC `@Impl(contract)` 装饰器暴露，错误经 `restErrorResponseBodyEncoder` 归一为 HttpExceptionFilter 可识别的响应体。
- 模块间守卫注册顺序受 `app.module.ts` 导入序约束：限流 → 会话 → 租户 → 业务，新增全局守卫需遵循该契约。
- 可选叠加层（features/*）通过 `feature-loader.ts` 运行期探测装配，并以空数组降级，确保主应用构建不被具体叠加层绑定。
