模块以 NestJS `@Global()` 的 `SubscriptionsModule` 为装配入口，采用 CQRS + DDD 分层：
- `api/`：HTTP 控制器 `SubscriptionsController`，通过 `CommandBus`/`QueryBus` 调用 core 层命令/查询处理器；路由级守卫（`TenantIsolationGuard`、`AuthorizationGuard` + `@Can`）保证租户隔离与权限。
- `infrastructure/`：所有持久化与外部系统适配集中于此，按职责再分 `entities/`（MikroORM 实体 `TenantSubscription`）、`repositories/`（`MikroSubscriptionRepository` 实现 domain port `SUBSCRIPTION_REPOSITORY`）、`dispatchers/`（`OrganizationStatusSubscriptionLinkHandler` 消费 `OrganizationStatusTransitionedEvent` 触发订阅状态收敛）、`mikro-subscription.lifecycle.ts`（`MikroSubscriptionLifecycle` 实现 `SUBSCRIPTION_LIFECYCLE`，支持 ES R4c 真相源写路径开关）、`payment-customer.provisioner.ts`（`CustomerProvisioner` 适配 `PaymentService`）。
- `quota/`：仅保留测试文件，配额服务/守卫/Store 由 core 提供，本模块通过 `QUOTA_STORE` 端口注入 Mikro 适配 `MikroQuotaStore`。
依赖方向单向指向 `@core/saas-kit` 的 domain ports（`SUBSCRIPTION_REPOSITORY`、`SUBSCRIPTION_LIFECYCLE`、`CUSTOMER_PROVISIONER`、`ES_TRUTH_SOURCE_SUBSCRIPTIONS`、`QUOTA_STORE`），本模块只负责具体实现绑定，核心逻辑在 core 层。
