- 对外部系统交互统一通过 core 层定义的 token 常量（如 `SUBSCRIPTION_REPOSITORY`、`SUBSCRIPTION_LIFECYCLE`、`CUSTOMER_PROVISIONER`、`ES_TRUTH_SOURCE_SUBSCRIPTIONS`、`QUOTA_STORE`）进行 DI 绑定，实现端口倒置。
- 租户隔离在仓储层通过 `TenantIsolationService.requireActiveTenantId()` 作为 fail-closed 卡点，用户面写入前强制解析 ALS tenantId，治理侧消费者则显式接收 `tenantId` 参数绕过 ALS。
- 跨上下文协作（如组织状态变更 → 订阅状态收敛）一律经领域事件（`OrganizationStatusTransitionedEvent`）+ `@EventsHandler` 处理，避免直接耦合其他模块。
- 状态迁移走终态收敛语义：`convergeStatus` 查找最新 from 态行，不存在即 no-op，天然幂等，重投/滞后不产生副作用。
- ES 真相源写路径通过 `ES_TRUTH_SOURCE_SUBSCRIPTIONS` 布尔旋钮切换：关闭时直写投影表，开启时先 append 事件流再 fold 回写投影，四端口均 `@Optional` 装配。
- MikroORM 实体以 `TableMeta` + `buildRuntimeEntity` 定义列元数据单源，并复用 `TENANT_ISOLATION_FILTERS` 实现行级租户过滤。
