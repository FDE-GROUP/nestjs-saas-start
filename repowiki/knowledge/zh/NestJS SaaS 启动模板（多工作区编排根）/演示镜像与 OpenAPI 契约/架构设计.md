模块由两个互不依赖的子目录组成：
- `docker/demo/`：单 Dockerfile（`Dockerfile.demo`）把 SaaS 应用（Node/pnpm 多 workspace 构建产物）、Odoo 20 CE、PostgreSQL 18 打包进同一镜像；`entrypoint.sh` 在首次启动时 initdb、建库、跑 MikroORM 迁移与 seed、初始化 Odoo 数据库并预置 OAuth provider 与用户，随后后台拉起 PG、Nest API（内网 :7011）、Odoo HTTP（:8069）和 Node 内置的 `login-gate.mjs` 登录门（对外 :7009），通过同源子路径 `/app/`、`/odoo-rpc/` 静态服务 apps/web 与 odoo-rpc-web 的 SPA 构建产物。
- `openapi/openapi.yaml`：OpenAPI 3.1.0 文档，声明 `/api/v1.0` 下的 health、posts、users/me/data-export 等端点，作为 API 契约的单一事实来源。
依赖方向单向：demo 镜像消费上层 `apps/api`、`apps/web`、`apps/odoo-rpc-web` 的构建产物；openapi 仅描述接口，不被运行时引用。
