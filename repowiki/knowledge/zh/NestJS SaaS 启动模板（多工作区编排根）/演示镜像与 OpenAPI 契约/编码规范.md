- 演示环境的所有敏感值（JWT_SECRET、BETTER_AUTH_SECRET、SSO_OAUTH_CLIENTS 等）以带 `demo-only-insecure-*` 前缀的环境变量默认值注入，明确标注非生产用途。
- 容器内进程按角色切换用户执行：PG 用 `su postgres`，Odoo 用 `su odoo`，避免 root 直接操作数据库与服务。
- 首次初始化通过写入 `/var/lib/demo-pg/.initialized` 标记文件做幂等判断，跳过已初始化的分支直接拉起服务。
- 登录门与上游 Nest API 保持同源（`:7009` 对外、`:7011` 内网），并通过环境变量 `WEB_BASE`/`ODOO_RPC_BASE` 对齐前端 vite base 与静态挂载前缀，使会话 cookie 天然共享。
