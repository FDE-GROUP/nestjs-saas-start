- 路由定义统一采用 `createFileRoute('/path')({...})` 导出 `Route` 常量，并在 loader 首行调用 `await requireSession()` 进行登录校验。
- URL 查询参数通过 `validateSearch` 强类型化为本地接口（如 `TenantSearch`/`UserSearch`），再经 `loaderDeps` 注入 loader，避免直接访问 `ctx.search`。
- loader 返回统一的结构体 `{ kind: 'ok' | 'error', page?, offset, q, denied?, body? }`，组件据此分支渲染成功列表或 `ErrorPanel`，403 错误标记为 `denied` 以显示权限提示。
- 分页通过 `offset` + `LIMIT=20` 控制，翻页与搜索均通过 `navigate({ to, search })` 更新 URL 而非本地状态驱动。
- 写操作统一使用 `useAction()` 包装 `rpc.*` 调用，传入 `path`/`method`/`scope`/`successMessage`/`thunk`，并通过 `Feedback` 组件展示 pending/error/success 状态。
