三个文件构成平台运营段的页面层：
- `platform.tsx` 是 `/platform` 外壳路由，通过 `requireSession()` 做登录校验，渲染顶部导航（租户治理、用户治理）并挂载 `<Outlet />`；权限最终由后端 `PlatformOperatorGuard` 在 loader 中裁决。
- `platform.tenants.tsx` 实现 `/platform/tenants` 列表页，使用 `createFileRoute` + `validateSearch` + `loaderDeps` 将 URL search (`offset`, `q`) 强类型化后注入 loader，调用 `rpc.platform.tenants.list` 分页拉取数据；同时作为父路由承载 `/platform/tenants/$tenantId` 子路由（命中时通过 `useMatchRoute` 早退到 `<Outlet />`）。
- `platform.users.tsx` 实现 `/platform/users` 列表页，复用相同的数据加载模式，并通过 `useAction` + `rpc.platform.users.suspend/resume` 实现行内暂停/恢复的写操作，成功后触发 `router.invalidate()` 刷新 loader。
依赖方向单向向外：页面 → `../lib/api` (rpc) / `../lib/session` / `../lib/mutation` / `../components/*`，不反向引用业务逻辑。
