- 受保护路由通过根路由 `beforeLoad` 集中守卫，公开路径以 `Set` 白名单声明，新增匿名页只需追加集合而非分散判断。
- API 响应采用本地 `extractXxx(raw)` 防御形函数做窄类型转换，配合 try/catch + `logApiError` 降级为空数组或 null，避免直接强转后端契约。
- 写操作统一通过 `useAction()` 封装 `thunk` + `path/method/scope/successMessage` 配置，由 `SubmitButton` 与 `Feedback` 消费 pending/error/success 状态。
- 导航项使用 `Link` 的 `activeProps={{ 'aria-current': 'page', className: NAV_ACTIVE }}` 实现命中态样式覆盖，基类与活动类分别常量化以避免重复。
