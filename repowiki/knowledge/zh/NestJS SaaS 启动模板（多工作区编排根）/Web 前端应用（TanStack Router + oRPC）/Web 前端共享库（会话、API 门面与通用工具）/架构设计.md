模块按职责拆分为若干独立文件，无子目录，依赖方向单向向外：
- 网络层：`api.ts` 导出 `rpc`（基于 `@saas/api-client` 的 oRPC typed 客户端，路径 `/api/v1`，同源 Cookie 凭据）；`auth.ts` 以裸 fetch 直连 Better Auth 端点，作为 multipart/非 oRPC 场景的例外；`upload.ts` 是存储上传的 multipart carve-out。
- 会话层：`session.ts` 暴露 `requireSession` / `redirectIfAuthenticated` 两个 loader 级守卫，复用 `auth.getSession` 并借助 `safe-redirect` 做回跳白名单。
- 业务辅助：`mutation.ts` 提供 `useAction` hook 统一 mutation 状态 + `router.invalidate()` 重载 + 结构化错误记录；`organization-context-guide.ts` 用 `errorCodeOf` 判别缺租户 403 并探测成员关系。
- 横切工具：`format.ts`（日期/错误体解析）、`log.ts`（dev 结构化 console.error + requestId 关联后端）、`validation.ts`（复用 zod schema 做本地拦截）、`theme.ts` + `theme-provider.tsx`（React Context 主题）。所有文件均附带同名 `.test.ts`，测试与实现一一对应。
