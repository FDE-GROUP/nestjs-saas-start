模块由三个 TanStack `createFileRoute` 文件路由组成：
- `/login`（login.tsx）：提供邮箱密码登录与魔法链接登录两个子表单，通过 `beforeLoad` + `redirectIfAuthenticated` 拦截已登录用户，使用 `validateSearch` 解析 `?next` 并在成功后经 `safeInternalPath` 校验后 SPA 跳转。
- `/register`（register.tsx）：仅开发环境可用的注册页，结构与登录页同构，调用 `signUpEmail` 并复用同一套 `next` 回跳模式。
- `/invitations`（invitations.tsx）：受保护的组织邀请列表页，通过 loader 内 `requireSession()` 守卫，加载后以 `useAction` 驱动接受/拒绝操作，调用 `rpc.organizations.*` 发起 API 请求。
依赖方向单向向外：路由组件 → `../lib/auth`（签名/注册）、`../lib/session`（会话守卫）、`../lib/api`（RPC 客户端）、`../components/*`（UI 原子组件），不反向引用业务逻辑层。测试文件（login.test.tsx、register.test.tsx、invitations.test.tsx、login-redirect.test.tsx）按路由一一对应，覆盖正常流程与重定向边界。
