- 路由通过 `createFileRoute` 导出 `Route` 常量，并在配置对象中声明 `beforeLoad`、`loader`、`validateSearch` 与 `component`。
- 需要鉴权的路由在 `beforeLoad` 或 `loader` 中调用 `redirectIfAuthenticated` / `requireSession` 进行入口守卫，未登录时弹离到 `/login`。
- 成功登录后统一通过 `safeInternalPath(search.next)` 校验目标路径，合法则 `navigate({ href })`，否则回退到首页，避免开放重定向。
- 表单状态采用 `pending` / `error` / `notice` 三态 useState 组合，提交前 `setPending(true); setError(null)`，异步完成后根据 outcome.ok 分支处理。
- 受保护的写操作统一通过 `useAction()` 包装，传入 `{ path, method, scope, successMessage, thunk }` 结构调用 RPC，并由 `SubmitButton` / `DangerButton` + `Feedback` 展示结果。
