模块以 `src/index.ts` 为单一汇面，按职责拆分为三个子文件：
- `rpc-client.ts`：核心层，基于 `@orpc/client` 的 `createORPCClient` + `OpenAPILink` 构建 typed 客户端；通过 `buildClientRouterView` 把 `@saas/api-contract` 的 `AppRouterContract` 转成 OpenAPI 模板（`:name` → `{name}`），并注入 `customErrorResponseBodyDecoder` 将 Nest REST 错误体映射为 `ORPCError`；出网前用 `unwrapRestEnvelope` 剥去后端 `TransformInterceptor` 的 `{data,statusCode,message}` 成功信封，入网后用 `reviveIsoDateStrings` 把 UTC ISO 串可逆还原为 `Date`。
- `envelope.ts`：纯类型契约定义（`ApiEnvelope` / `ApiErrorBody` / `PageResult` / `CursorPageResult`），配合 `_Exact` 编译期锁 + `API_ENVELOPE_KEYS` / `API_ERROR_BODY_KEYS` 常量数组对拍后端实存产物，禁止静默漂移。
- `errors.ts`：错误码消费面，re-export `@core/saas-kit/shared-kernel/errors/error-codes` 的单源码表，并提供 `errorCodeOf` / `hasErrorCode` / `ApiError` 等判别原语。
依赖方向单向：本包仅依赖 `@core/saas-kit`、`@orpc/*`、`@saas/api-contract`，不反向被业务代码直接引用——上层通过 `createRpcClient()` 获取 `RouterContractClient<AppRouterContract>` 调用 procedure。
