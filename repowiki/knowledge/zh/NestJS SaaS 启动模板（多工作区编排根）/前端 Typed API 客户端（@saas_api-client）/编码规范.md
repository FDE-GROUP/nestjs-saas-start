- 对外暴露的契约类型（如 `ApiEnvelope`、`ApiErrorBody`）均配套一个 `*_KEYS` const 数组，并通过 `_Exact` 泛型断言在编译期锁定接口字段集与键数组完全一致。
- REST 成功响应经 `unwrapRestEnvelope` 剥离 `{data,statusCode,message}` 信封后再返回给调用方，错误路径则经 `decodeRestErrorBody` 转为 `ORPCError` 透传。
- 日期字段采用「规范 UTC ISO 串」上 wire、客户端侧用正则 `CANONICAL_ISO_UTC` 校验后 `new Date` 可逆还原，避免误伤普通字符串。
- HTTP status 到 oRPC code 的映射集中在 `STATUS_TO_ORPC_CODE` 表中，未知码回退按 4xx→BAD_REQUEST、5xx→INTERNAL_SERVER_ERROR 归类。
- 错误码相关能力（码表、判别函数）一律 re-export `@core/saas-kit/shared-kernel/errors/error-codes`，不在本包内维护第二份码源。
