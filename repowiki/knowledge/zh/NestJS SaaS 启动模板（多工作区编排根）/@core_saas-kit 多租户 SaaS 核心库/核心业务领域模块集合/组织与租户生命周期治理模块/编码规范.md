- 状态词汇集合以 `as const` 对象导出（如 `TENANT_STATUS`、`USER_STATUS`、`ORG_VISIBILITY`），并派生同名字面量联合类型 `(typeof X)[keyof typeof X]`，保证值域单源。
- 持久化访问统一采用「端口」模式：定义接口 + `Symbol` token（`TENANT_STATUS_STORE`、`USER_STATUS_STORE`），服务通过 `@Inject` 注入，避免直接耦合数据库表结构。
- 状态迁移服务暴露统一的 `transition(id, to, options?)` 方法，返回结合类型 `{ kind: 'ok'|'not-found'|'illegal', ... }`，调用方据此映射 404/409。
- 所有写操作（upsert + 事件发布）包裹在 `uow.run(async () => {...})` 中，确保 outbox 与数据行同事务原子提交。
- 领域事件类继承 `DomainEvent<Payload>`，固定声明 `EVENT_TYPE` / `EVENT_VERSION` / `AGGREGATE_TYPE` 静态字段，并在构造时透传 `aggregateId` 与 `correlationId = currentRequestId()`。
- 纯判定逻辑（`isTenantBlocked`、`isOrgIsolated`、`canTransition`）保持无框架依赖的纯函数形态，与 NestJS 服务解耦。
