模块按「端口 + 实现」分层：
- 端口定义（`platform-config.port.ts`、`platform-identity.port.ts`）通过 `Symbol` token（`PLATFORM_SETTINGS`、`PLATFORM_IDENTITY_LOOKUP`）暴露 `PlatformSettings.operatorEmail()` 与 `PlatformIdentityLookup.emailOf(userId)`，使 core 不依赖应用侧的 `ConfigService` 或 user 表结构。
- 守卫实现（`platform-operator.guard.ts`）作为 Nest `CanActivate`，组合 `SESSION_READER`、`PLATFORM_IDENTITY_LOOKUP`、`PLATFORM_SETTINGS` 与 `UserStatusService`，按「无会话→401；被封禁/未配置/email 不命中→403」的 fail-closed 顺序裁决 FR-11/FR-13 的平台 Operator 权限。
- 审计单点（`platform-audit.service.ts`）统一承载 FR-6/S5 的租户与用户治理动作，采用「pino 结构化日志（所有调用）+ `AUDIT_LOG_STORE` 耐久账本（仅成功动作）」双通道模式，并通过 `currentRequestId()` 关联请求。
依赖方向单向向外：core 消费 shared-kernel（audit-log.store、request-context、errors）与 tenant-isolation（session port），不被应用侧反向依赖。
