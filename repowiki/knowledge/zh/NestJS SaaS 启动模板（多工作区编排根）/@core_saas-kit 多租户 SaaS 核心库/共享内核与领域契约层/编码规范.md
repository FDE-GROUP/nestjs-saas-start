- DI 端口以 `export const XXX = Symbol('XXX')` 形式声明注入 token，并配套导出对应接口（如 EVENT_STORE、UNIT_OF_WORK、AUDIT_LOG_STORE）。
- 领域事件继承自 `DomainEvent<TPayload>` 抽象基类，由构造函数自动填充 eventId（uuidv7）、occurredAt、eventVersion 等元数据，payload 保持强类型。
- 业务错误码集中在 `ERROR_CODES` 对象中按限界上下文命名空间（AUTH/ORG/USER/BILLING/MCP 等）分组声明，并以 `NAMESPACE:NAME` 文法约束，消费方只引用常量而非字面量。
- 跨进程/跨模块的稳定标识（事件名、错误码）采用集中单源声明模式，配合正则 `ERROR_CODE_PATTERN` 做运行时校验，防止散落字面量漂移。
- 对外 API 通过 `libs/core/src/shared-kernel/index.ts` 统一 re-export，子目录不直接向外暴露，形成单一公共入口。
