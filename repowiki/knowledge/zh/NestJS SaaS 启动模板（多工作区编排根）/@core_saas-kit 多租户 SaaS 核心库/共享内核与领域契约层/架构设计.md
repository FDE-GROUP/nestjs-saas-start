本模块是 libs/core 下的纯类型/工具层，不依赖 Nest/ORM，仅暴露面向上层应用（apps/api、modules/*）的稳定契约：
- `domain/`：定义 `DomainEvent` 抽象类及其 props（含 eventId/aggregateId/correlationId/causationId 等 ES 信封字段），并通过 `*.port.ts` 文件声明 EventStore、EventPublisher、UnitOfWork 等 DI 端口（以 `Symbol('...')` token 注入），实现由参考应用侧装配。
- `context/request-context.ts`：基于 Node `AsyncLocalStorage` 维护每请求 requestId，供事件构造点读取 correlationId。
- `audit/audit-log.store.ts`：治理审计账本的 append-only 端口（AuditLogStore），与事件流解耦，单独持久化到 `audit_log` 表。
- `errors/error-codes.ts`：集中声明 `NAMESPACE:NAME` 文法的业务错误码常量及 `isErrorCode` 校验器，作为前后端稳定机器契约。
- `util/uuid-v7.ts`：手写 RFC 9562 UUIDv7 生成器，避免对 Node 原生 crypto.v7id 的版本绑定。
- `cqrs/types.ts`、`domain/domain-event-names.ts`、`domain/pagination.ts`：CQRS 类型、事件名常量、分页 DTO。
- 所有对外符号通过 `index.ts` 统一 re-export，形成单一公共入口；内部依赖方向单向：domain → util/context/errors，audit 独立于 domain。
