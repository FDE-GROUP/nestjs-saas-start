libs/core 是一个私有 npm 包（@core/saas-kit），采用「共享内核 + 能力子模块」的分层结构：
- shared-kernel 提供纯 JS/TS 基础类型（DomainEvent、EventStore/EventPublisher 端口、Pagination、ErrorCodes、UUIDv7、RequestContext、CQRS types），不依赖 NestJS；它是唯一被 index.ts 稳定再导出的内容。
- authorization、tenant-isolation、platform 是面向 NestJS 的横切能力（Guard/Decorator/Middleware/Service），依赖 shared-kernel 的端口契约但不反向引用业务模块。
- modules/{organizations,subscriptions,workspaces} 是独立 DDD 子域，各自遵循 application/domain 分层并通过 ports 与外部解耦。
- package.json 通过 exports ./* 暴露所有子路径，同时声明 @nestjs/common/core/cqrs 为 peerDependencies，强制消费方在自身应用中完成装配；index.ts 注释明确禁止从参考应用反向 import core，确保单向依赖方向。
