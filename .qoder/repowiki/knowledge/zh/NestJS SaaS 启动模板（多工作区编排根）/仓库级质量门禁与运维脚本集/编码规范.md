- 每个 verify-* 脚本同时导出可单测的纯函数核（如 `findViolationsFromRelPaths`、`computeCounts`、`evaluate`、`analyzeBindingDrift`）与 CLI main，CLI 仅负责 I/O 与 exit code。
- 脚本通过 `fileURLToPath(import.meta.url)` 推导 `REPO_ROOT = resolve(..., '../..')`，再以 `join(REPO_ROOT, 'apps' | 'libs' | 'scripts/...')` 定位仓库资源，避免硬编码绝对路径。
- 所有 CLI 在文件末尾用 `if (process.argv[1] && fileURLToPath(import.meta.url) === resolve(process.argv[1])) { main(); }` 守卫，使模块既可被 require/import 又可独立执行。
- 终端输出统一通过 `isTTY && !NO_COLOR` 条件包裹 ANSI 转义码（GREEN/RED/BOLD/DIM/RST），保证 CI 管道无彩色干扰。
- 恒等闸采用「纯文本/目录扫描 + exit 1 失败」模式，不启动构建、不连 DB，确保快速失败并可在 full/quick 双模式运行。
- doctor 类脚本将核心判定逻辑与 I/O 解耦：drift 分析放在 `odoo-binding-drift.ts` 中，`odoo-binding-doctor.ts` 仅负责取两侧事实并喂入纯函数。
