- HTTP 端点通过 `@Impl(contract)` 装饰器声明契约，并在方法体内用 `os.input(...).output(...).meta(...).handler(...)` 链式构造处理器。
- 外部依赖一律以类 token 注入并显式标注 `@Inject(ClassName)`，而非直接使用类名作为 token。
- 对上游 Odoo 返回的缺失值统一通过 `textOf` / `nullableTextOf` / `numberOf` 等归一函数处理，非预期类型抛 `BadGatewayException` 以捕获模式漂移。
- 租户到 Odoo 公司的访问控制集中由 `resolveReadyCompanyId` 单点裁决，结合 `canUseOdoo` 与 `ForbiddenException(errorCode: ORG_ODOO_BINDING_NOT_READY)` 实现 fail-closed。
- Odoo 侧安全边界通过 `scopedCompanyDomain` 强制注入 `company_id` 过滤项，并通过 `companyContext` 附带 `allowed_company_ids` 纵深防御。
