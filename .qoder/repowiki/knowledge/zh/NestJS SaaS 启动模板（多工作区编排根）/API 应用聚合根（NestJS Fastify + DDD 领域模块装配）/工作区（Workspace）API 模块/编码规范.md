- 控制器方法统一使用 `@UseGuards(TenantIsolationGuard, AuthorizationGuard)` 组合守卫，并在方法上叠加 `@Can(action, 'Workspace')` 声明权限，而非在类级别集中配置。
- 仓储实现中所有 DB 访问前调用 `this.scope()` 取 `requireActiveTenantId()` / `requireActiveOrganizationId()`，并将 `tenantId` 作为固定最后键拼入 where 谓词，确保租户过滤不可被上层覆盖。
- 通过 `MikroOrmService.fork()` 为每次操作获取独立 EntityManager，禁止共享全局 em。
- 响应 DTO 文件末尾放置双向赋值断言（如 `_wfwd` / `_wbwd`），用 TypeScript 结构等价性锁死 Swagger DTO 与领域 ReadModel / contracts 输出类型的漂移。
- 实体定义采用 `TableMeta` + `buildRuntimeEntity` 双产物模式：同一份元数据同时产出迁移实体与运行时 EntitySchema，避免描述重复。
