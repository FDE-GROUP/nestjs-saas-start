- 对外暴露的实体行一律经显式映射函数投影为白名单字段，禁止直接透传 entity 行（如 `toRowView` 剥除 `tokenHash`/`tenantId`）。
- 安全敏感错误统一收敛为含 `errorCode` 的 `HttpException`，且对「不存在/已撤销/已过期」等分支返回同一状态码与消息以防探测（见 `McpTokenVerifierService.invalid` 与 `McpCredentialService.revoke`）。
- 进程内资源（会话 Map、transport）在创建/命中路径做惰性回收，并通过 `MAX_SESSIONS` + LRU 逐出上限防止无界增长。
- 工具可见性由静态 `MCP_TOOLS` 表声明 `requiredScope`，运行时通过 `selectToolNames(granted)` 过滤，实现 deny-by-default 的 scope→工具映射。
- 跨属主边界的依赖一律通过 `@app/modules/auth/application/ports/*` 端口注入（`MCP_ACCESS_TOKEN_STORE`、`MCP_TOKEN_VERIFIER`），本模块不直接 import 属主实体。
