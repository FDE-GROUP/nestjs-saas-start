- HTTP 控制器类级统一标注 `@TenantIsolationExempt()` + `@UseGuards(PlatformOperatorGuard)`，表明所有路由均为跨租户的平台治理入口，不绑定租户作用域。
- 路由方法采用 `@Impl(contract)` + `os.input(schema).output(schema).meta(meta).handler(...)` 链式注册，输入/输出/元数据分别来自 `@saas/contracts` 与 `@saas/api-contract` 的单源定义。
- 写操作通过 `CommandBus.execute(Command, ...)` 委派到 `@app/modules/organizations/application/commands/*`，读操作通过 `QueryBus.execute(Query)` 委派到对应 query，控制器内不直接访问仓储或 ORM。
- 未命中资源统一抛出 `NotFoundException('... not found', { errorCode: ERROR_CODES.* })`，由 WP-D 错误面承接为 REST 404 信封。
- 对 core 的抽象（`PlatformSettings`、`PlatformIdentityLookup`）在 `infrastructure/` 下以具体类实现并经由 `provide/useClass` 绑定到 token，保持端口与实现的解耦。
