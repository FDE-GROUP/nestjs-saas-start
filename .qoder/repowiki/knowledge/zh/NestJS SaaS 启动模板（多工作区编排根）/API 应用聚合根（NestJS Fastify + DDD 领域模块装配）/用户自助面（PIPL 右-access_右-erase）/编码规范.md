- CQRS 用例以成对文件组织：`application/<command|query>/<name>.<command|query>.ts` 定义命令/查询类，`handlers/<name>.<command|query>-handler.ts` 用 `@CommandHandler` / `@QueryHandler` 装饰器注册处理器。
- 领域持久化通过 `domain/repositories/*.repository.ts` 中的 Symbol token（如 `USER_REPOSITORY`）+ 接口声明端口，具体 ORM 适配放在 `infrastructure/repositories/` 并在 `*.module.ts` 中 `{ provide: TOKEN, useClass: Impl }` 绑定。
- 所有数据库访问使用 `MikroOrmService.fork()` 获取独立 EntityManager，避免共享全局 em 导致串租户问题。
- 敏感列（password、token、evidence 等）在导出查询中通过 MikroORM `fields` 白名单在 SQL SELECT 层面排除，而非取回后过滤。
- 跨域写操作统一走属主域的端口注入（如 `AUTH_USER_STORE`），本模块不对 user 表直接写，保持 users 上下文为纯读 + 委托写的边界。
