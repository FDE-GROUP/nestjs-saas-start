- 所有对外部导入的 NestJS 服务均使用显式 `@Inject(ClassName)` 装饰器配合值导入，避免 swc design:paramtypes 退化。
- 对不可信输入（未知 `eventType`、`eventVersion > SUPPORTED_EVENT_VERSION`）一律 fail-loud 抛错或 parkRow，不在运行期静默吞异常。
- 事件行 → DomainEvent 实例的重建逻辑集中在 `event-hydration.ts` 与 `EVENT_TYPE_REGISTRY`，禁止在各消费方各自 switch 枚举。
- 数据库访问统一通过 `MikroOrmService.fork()` 获取独立 EntityManager，禁止直接读写全局 `orm.em`。
- 批量写入前先判空（`events.length === 0` return），确保空批不触库。
- outbox 投递采用「事务内 claim（置 `dispatchedAt`）+ 提交后 publishAll」两段式，失败仅记日志不回滚已提交的 claim，体现 best-effort 语义。
