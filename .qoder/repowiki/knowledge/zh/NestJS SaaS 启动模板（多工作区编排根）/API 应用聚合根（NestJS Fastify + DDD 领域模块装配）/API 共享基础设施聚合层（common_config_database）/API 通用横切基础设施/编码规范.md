- 全局横切能力通过 `@Global()` Module 集中注册 `APP_FILTER` / `APP_INTERCEPTOR` / `APP_GUARD`，而非在各业务模块重复声明。
- 错误响应体统一收敛到 `ErrorResponse` 信封，由 `error-envelope-fields` 单源生成关联字段，避免各过滤器自行拼装。
- Fastify 层配置（`buildFastifyHttpOptions`、`parseTrustedProxies`）与环境变量（`LOG_LEVEL`、`AUTH_TRUSTED_PROXIES`）集中在独立函数中，供 main 与测试复用。
- 每个可复用组件（filter、interceptor、hook、controller）均配套同名的 `.test.ts` 单元测试，保证横切逻辑可单独验证。
- oRPC 客户端/服务端一律从 `common/orpc` 导出的 `oc`/`os` 获取，禁止直接裸引 `@orpc/server`/`@orpc/contract`，以保证 REST 错误中间件不可绕过。
