模块由三层构成：
- 应用入口 `main.tsx`：通过 `createRouter` + `routeTree.gen`（由 `@tanstack/router-plugin` 在 dev/build 时生成）装配路由器，按 `import.meta.env.BASE_URL` 裁剪出 `basepath` 以适配镜像子路径部署；统一注入 `RouteError` / `RoutePending` 作为全局兜底错误与 pending 组件，并在 React 树顶层包裹 `ThemeProvider`。
- 根路由 `routes/__root.tsx`：使用 `createRootRoute` 定义全局 `beforeLoad` 守卫——白名单 `PUBLIC_PATHS = { '/login', '/register' }` 外的所有路径均经 `requireSession` 校验，未登录则重定向至 `/login?next=<原路径>`；渲染 `RootLayout`，根据 `useSession().status` 动态展示已认证导航或仅「登录」入口，并集中提供登出按钮与 `ThemeToggle`。
- 首页 `routes/index.tsx`：通过 `createFileRoute('/')` 的 `loader` 串行拉取 `organizations.list` → `tenants.list` → 自动激活唯一组织 → `subscriptions.current`，并以防御形函数 `extractOrganizations` / `extractTenants` 兼容后端非 typed 返回；页面内嵌租户/组织双层切换器（调用 `rpc.tenants.setActive` / `rpc.organizations.setActive`）与零组织引导面板（提交 `POST /api/v1/organizations/applications`），状态管理统一走 `lib/mutation` 的 `useAction` hook。
依赖方向单向向下：入口 → 路由 → 业务组件 → `lib/*`（session/auth/api/format/log），不反向引用。
