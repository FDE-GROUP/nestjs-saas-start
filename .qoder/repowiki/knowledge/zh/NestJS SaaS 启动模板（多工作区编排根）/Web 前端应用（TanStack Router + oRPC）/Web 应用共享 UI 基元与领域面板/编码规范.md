- 领域面板组件采用「纯展示 + 回调外置」模式：状态变更通过 onXxx 回调注入，组件自身不持有 mutation/router 状态，便于脱离业务上下文单测 enable/disable 矩阵。
- 后端枚举/状态机在前端以 Record<T, string> 映射表（LABELS/STYLES/SUBJECT_LABELS/ACTION_LABELS/PLAN_LABELS）集中维护中文文案与样式，未知值回落到原串或默认样式以防渲染崩溃。
- 生命周期动作可用性由独立的判定函数（`actionEnabled`、`userActionEnabled`、`grantedCellSet`、`seatState`）计算布尔结果，按钮的 disabled 属性直接复用该结果，避免在 JSX 中内联状态机逻辑。
- 破坏性操作按钮统一使用 DANGER 样式类（红色边框 + hover 背景），普通操作使用 BTN 样式类，并通过 title 属性描述状态转换语义（如 '暂停（active→suspended）'）。
- 错误与空态反馈通过 `<p role="alert">` 或 ErrorPanel/EmptyPanel 呈现，并配合 dark: 变体类名同时覆盖亮色/暗色主题。
- 组件注释以 JSDoc 形式标注所属 Epic/模块章节（如 'Epic 06 §6.1'、'module-frontend-platform §F4b'），并在行内以「待裁点②甲」等标记遗留 TODO。
