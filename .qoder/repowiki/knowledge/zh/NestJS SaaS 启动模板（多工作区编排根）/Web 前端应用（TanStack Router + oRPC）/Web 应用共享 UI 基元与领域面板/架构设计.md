本模块是 apps/web 下的共享 UI 层，按职责拆分为四类文件：
- 通用基元：`panels.tsx`（SectionHeading/EmptyPanel/ErrorPanel）、`forms.tsx`（Field/Select/SubmitButton/DangerButton/Feedback/FormWrap），均为无状态、仅用 Tailwind 的原子组件。
- 领域面板：`billing-panels.tsx`（订阅快照、支付通道、升级表单）、`platform-users.tsx`（平台用户列表 + 生命周期动作）、`platform-tenants.tsx`（租户状态徽标 + 生命周期动作 + 组织审批动作）——三者均从 `@saas/contracts` 取契约类型，将后端状态机镜像为前端 enable/disable 判定函数（如 `actionEnabled`、`userActionEnabled`、`seatState`）。
- 权限矩阵：`rbac-matrix.tsx` 通过 `GrantRolePermission['subject'|'action']` 把后端枚举直接映射到前端联合类型，并以 `SUBJECTS/ACTIONS` 常量驱动 6×5 网格渲染。
- 路由兜底与交互：`route-feedback.tsx` 作为 TanStack Router 的 error/notFound/pending 组件；`theme-toggle.tsx` 消费 `../lib/theme-provider` 的 `useTheme()`；`organization-context-guide.tsx` 在缺活跃租户时给出导航引导。
依赖方向单向向外：组件只依赖 `@saas/contracts`、`../lib/*` 和同级兄弟组件，不反向被业务页面以外的模块引用；所有副作用（mutation、router hook）外置为回调 props，使每个组件可独立单测。
