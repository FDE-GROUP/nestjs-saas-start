- 对外 API 以纯函数 + TypeScript 接口形式导出，避免隐式全局单例（如 rpc、getSession、clientValidate），便于测试 mock。
- 错误处理走 `format.apiErrorDetail` + `log.logApiError` 双通道：前者产出可读文案，后者在 dev 附 `{requestId, statusCode, errorCode}` 字段对象以便与后端 LoggerService 关联。
- 对后端返回的错误体兼容新旧两条链路：通过检查 `name === 'ORPCError'` 鸭形判断是否从 `.data` 解包 REST 体，使 `describeApiError` / `useAction` 对 oRPC 与 openapi-fetch 表现一致。
- 受保护路由统一在 loader 首行调用 `requireSession` 或 `redirectIfAuthenticated`，未登录时通过 TanStack Router 的 `redirect` 抛出跳转，而非自行 `navigate`。
- 安全敏感的重定向入口（登录后 next、已登录回跳）一律经 `safeInternalPath` 白名单校验，仅放行以 `/` 开头的站内相对路径。
- 每个实现文件旁放置同名 `.test.ts`，测试与源码一一对应，覆盖会话、格式、日志、验证、主题、安全重定向等公共能力。
