本模块是 web 端的唯一前端入口，按职责拆分为五个子模块：
- app_shell 在 main.tsx 中初始化 TanStack Router、挂载 ThemeProvider 与根路由 __root.tsx，并注入全局导航布局与会话守卫。
- routes/ 下的所有页面均遵循文件式命名约定（如 platform.tenants.$tenantId.tsx、settings.roles.$roleKey.tsx），由 routeTree.gen.ts 自动生成类型化路由表。
- shared_libs 提供跨页面依赖：auth.ts/use-session.ts 封装会话校验与安全回跳，api.ts 暴露基于 oRPC 的客户端调用，session.ts/theme.ts/organization-context-guide.ts 等提供运行时状态。
- shared_components 为各业务页提供无业务耦合的 UI 基元（表单、RBAC 矩阵、计费面板、平台租户/用户治理面板）。
- auth_routes / platform_admin / settings_pages 作为具体业务路由层，仅消费 shared_libs 的 API 门面与 shared_components 的 UI 组件，不直接访问后端。

子模块间通信契约集中在 shared_libs/api.ts（oRPC 客户端）与 session/auth 工具上；路由树由 TanStack Router 代码生成器维护，新增页面需同时更新 routeTree.gen.ts。
