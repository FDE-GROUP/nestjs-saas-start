每个 `.tsx` 文件即一个独立的路由页面，通过 `createFileRoute('/settings/<slug>')` 注册到 React Router 的文件式路由表；所有页面在 loader 中统一调用 `requireSession()` 做鉴权守卫，再按业务拉取数据或返回空。
- 读多写少：billing/members/roles/storage 等写操作统一经 `useAction()` + `rpc.*` oRPC 客户端发起，成功消息与错误状态由 `Feedback` 组件消费。
- 组织上下文缺失时回退到 `OrganizationContextGuidePanel`（members、roles 通过 `probeOrganizationContext` 探测后渲染引导面板）。
- 纯展示子组件（如 `MembersView`、`RolesView`、`UploadResultPanel`、`HealthStatusPanel`、`OdooIntegrationPanel`、`PaymentIntegrationPanel`）被显式 `export` 出来，以 typed 契约类型（来自 `@saas/contracts`）驱动、无 fetch 逻辑，便于单测锁定接口形状。
- 依赖方向单向：页面 → `../lib/api`（rpc）、`../lib/mutation`（useAction）、`../lib/session`（requireSession）、`../components/*`（表单/面板），不反向引用其他 settings 页面。
