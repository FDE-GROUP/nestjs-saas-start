- 路由页面统一通过 `createFileRoute('/settings/<path>')` 导出 `Route`，并在 loader 首行调用 `await requireSession()` 完成鉴权。
- 写操作一律使用 `useAction()` 包装，传入 `{ path, method, scope, successMessage, thunk: () => rpc.* }` 结构，再由 `Feedback` 消费 pending/error/success。
- API 调用失败时在 try/catch 内调用 `logApiError({ path, scope })` 并配合 `describeApiError` 渲染用户可读提示。
- 需要组织上下文的页面在 loader 捕获错误后调用 `probeOrganizationContext(e)`，若返回 guide 则渲染 `OrganizationContextGuidePanel`，否则回退到 `ErrorPanel`。
- 可复用的纯展示子组件以具名函数形式 `export` 出，参数类型直接引用 `@saas/contracts` 中的视图类型，组件内部不含网络请求。
- 危险操作（删除账号、移除成员、删除文件等）使用 `DangerButton` 而非普通 `SubmitButton`，并通过 `scope` 字段区分埋点维度。
