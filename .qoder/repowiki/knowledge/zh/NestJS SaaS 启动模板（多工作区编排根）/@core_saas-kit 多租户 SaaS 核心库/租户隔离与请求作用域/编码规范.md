- 对外扩展点以 Symbol token + interface 的 port 形式暴露（如 SESSION_READER、TENANT_SCOPE_RESOLVER），由应用侧注入具体实现，core 层不感知 ORM 或认证实现。
- fail-closed 语义统一通过抛出带 `ERROR_CODES.ISOLATION_NO_ACTIVE_CONTEXT` 的 `ForbiddenException` 表达，而非返回 null 或 false。
- 路由旁路采用装饰器 + Reflector 元数据模式（`@Public`、`@TenantIsolationExempt`），守卫通过 `getAllAndOverride` 同时检查 handler 与 class 级声明。
- 租户作用域的读写分离：中间件负责写入（`tenantIsolationStorage.run`），业务代码仅通过 `TenantIsolationService` 的只读 getter 获取，避免散点访问 ALS。
