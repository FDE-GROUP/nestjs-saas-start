    租户个人通道门面（module-rbac-casl §2.3.1·甲裁严格拆·self 侧）。

    Remarks

    与 OrganizationsOrgAdminController（管理门面）的分工：本控制器全部端点是「个人对自己成员资格/ 邀请的操作」——合法无 active 租户也可达（列表/接受邀请皆发生于入组前），故类级 @TenantIsolationExempt() 旁路租户墙、逐路由 SessionGuard 保会话必需；授权语义由 BA 数据面 自身裁决（membership 归属、被邀请人=本人、last-owner 不可退等），CASL 不介入 （CASL 矩阵管的是「租户内管理职权」，见 admin 门面）。

    数据操作 = BA auth.api.* 服务端直调（窄门面透传·BA 侧 hooks/校验照旧，含 seats 配额）， 不经被封堵的 BA 内置 org HTTP 面。
