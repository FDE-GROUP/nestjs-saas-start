    Remarks

    Tenant subscription repository port (domain-owned · global-tenancy S7 · FR-7/FR-8/D5).

    订阅是租户自有聚合，1:N 历史（每次改档新增一行·旧行留作升降级审计）。与 workspace port 同构： 不暴露 tenantId 参数——所属租户由 adapter 从可信 AsyncLocalStorage 上下文注入（requireActiveTenantId fail-closed·FR-5 单点），任何调用方都无法指向外部租户。配额裁决/限额读取属 QuotaService （tenancy 层单点），本 port 只管订阅行的写与历史读，避免限额逻辑散点。

    global-tenant-organization-rehierarchy 切片 D（计费单位上移）：订阅锚从 organizationId 升 tenantId—— 一租多组织后按租户总量控制席位/配额才是正当语义（organization_subscription→tenant_subscription）。
