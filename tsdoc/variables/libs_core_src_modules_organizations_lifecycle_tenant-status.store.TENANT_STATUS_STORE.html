    Remarks

    复裁定（人裁 2026-10-26「一租户多组织 · 一组织一公司」）将治理准入态从 organization.status 上移归位 tenant.status（Tenant = 隔离与计费边界·审批只管租户准入）。Organization 保留轻量 自有态（canUseOdoo 仍读 org.status active），但审批/暂停/恢复/驳回/删除的权威态是本端口。

    语义约定（仅锚定表为 tenant）：

    • readStatus：tenant.status NOT NULL 真列，本体存在即有值；本体行不存在 → undefined；
    • tenantExists：tenant 行命中与否——transition 的 not-found（404）判据；
    • upsert：治理迁移即变更——直写 tenant.status 并盖 updatedAt。

    存量一致性：切片 B 回填迁移 Migration20261026084000 已把 organization.status 原值搬入 tenant.status（1:1 骨架·同持治理态），换轴读写两侧一致，无孤儿态。
