    Remarks

    授权在我·数据在 DB：每端点声明 @Can(<动作>, 'Role'|'RoleGrant')，由 AuthorizationGuard 携 ALS 角色经 CASL（规则源 = 本租户 DB grant 行）裁决；通过后委派 TenantRbacAdminService 落库（写侧过 domain 策略闸 + 同通道审计行 + 写后失效投影缓存）。BA 内置 create-role/roles 端点 维持封堵（甲裁不代建→本片自建），本门面是租户差异化授权策略的唯一入口。

    @Can 落点与 seed 一致：owner/admin 持 Role(create/read/update/delete) + RoleGrant (create/read/delete)，member 无 → 非管理员请求由守卫 403（fail-closed）。
