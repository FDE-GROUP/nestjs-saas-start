    Odoo 公司绑定生命周期状态词汇（值域单源·迁移工件 CHECK 表达式与本声明序同式， wire 内联值集由 apps/api/src/common/contracts/contracts-vocab-parity.test.ts 对拍锁漂移）。

    Type Declaration

    • ReadonlyFAILED: "failed"
    • ReadonlyPENDING: "pending"
    • ReadonlyPROVISIONING: "provisioning"
    • ReadonlyREADY: "ready"

    Remarks

    null（列缺席）= 未绑定，不进本词汇表——与「无状态记录视同 active」的 deny-list 口径同构： 绑定维度的 fail-closed 由 canUseOdoo 单源裁决，不散点判 null。

    • pending：绑定意图已持久化，尚未开始建司（审批事件落库与 saga 领取之间）；
    • provisioning：建司/本地化基线/用户预配推进中；
    • ready：odooCompanyId 有效且公司可用——Odoo 能力的唯一放行态；
    • failed：任一步失败，带 odooFailureReason，重试/回找恢复由 doctor 与 saga 承接。
