    Remarks

    与 domain-event-names.ts 同构的集中声明纪律：errorCode 是跨前后端（api-client） 的稳定机器标识契约，必须在此单源声明、而非散落字面量；契约测试双向锁定 「码表值 ∈ NAMESPACE:NAME 文法」+「抛错点只引用本常量」，防旁逸/漂移。

    命名（microservice-readiness §4-② 已锁）：冒号分段 NAMESPACE:STABLE_NAME。

    • 用冒号而非点分：点分与领域事件名（user.registered）相撞，且撞 nestjs-i18n 键语法。
    • code 是机器标识，与人面可读消息（message，随 i18n 翻译）解耦——前端据 code 分支、据 message 展示。

    命名空间 = 按限界上下文（甲裁）：AUTH / ISOLATION / ORG / ROLE / GRANT / AUTHZ / USER / WORKSPACE / BILLING / STORAGE。 新增码一律先加此处，再在抛错点以 object response 携带（filter 透传·零新异常类）。
