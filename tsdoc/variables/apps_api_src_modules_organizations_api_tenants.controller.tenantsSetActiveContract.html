    Remarks

    列当前用户可见的租户（顶层）及其下组织（二级），供前端双层切换器。跨租可见（成员资格归组· 此刻尚无单一 active 租户可言），故类级 @TenantIsolationExempt() 旁路租户墙、逐路由 SessionGuard 保会话必需；可见面由仓储以 userId 收敛（成员资格归属），非独立隔离闸。只读——审批/切换仍走 organizations 准入面（saga 已随换轴归位租户态），本面不重复其写职责。例外（切片 4·D7）：新增 PUT /tenants/active——它不写租户生命周期态，只写当前会话的租级激活位（session-scoped）。
