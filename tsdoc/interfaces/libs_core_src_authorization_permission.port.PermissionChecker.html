    • listPredicate(
          check: PermissionListPredicateRequest,
      ): Promise<PermissionListPredicate>

      query 级列表过滤谓词（module-rbac-query-level-filtering 切片 B·dynamic-roles §2.4 缓账兑现·丁裁契约 additive）。

      Parameters

      • check: PermissionListPredicateRequest

        列表谓词入参

      Returns Promise<PermissionListPredicate>

      三态谓词（all / where / none）

      Remarks

      与 can 同源同口径：同一角色 + 同一 userId 下，列表可见集 = 逐条 can() 允许集（「列表 ⊆ 逐条」）。 三态返回（消费方=应用层列表面 handler·见参考应用 ListWorkspacesQueryHandler·人裁⑤）：

      • { kind: 'all' }：该角色对此 action/subject 存在无条件类型级授权（conditions=null 行） ⇒ 列表按 tenantFilter 全量（承 S2 类型级·无 instance 限制）；
      • { kind: 'where', where }：仅带 conditions 的授权 ⇒ 实例谓词（$or 并语义·人裁②），由消费方 AND 进 tenantFilter；
      • { kind: 'none' }：无任何匹配 grant 行 / 不可解析 / 加载失败 / 无租户无角色 ⇒ 空集（fail-closed·绝不回退全量）。
