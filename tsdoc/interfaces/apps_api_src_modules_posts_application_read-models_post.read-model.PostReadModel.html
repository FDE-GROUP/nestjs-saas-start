    Interface PostReadModel

    posts 上下文传输投影（application 层）：控制器/序列化契约（@saas/contracts PostView）的真相源。

    Remarks

    分层对齐后（module-posts-domain-entity-split）：端口流动领域实体 Post，本接口是其在 application 边界向 api/ 输出的传输形状——领域实体本身绝不越界进 api/（architecture「Entity Doctrine」· layer 依赖表 api/ 行）。字段形状与旧 PostRecord 等价，故响应双向赋值锁零变更。
