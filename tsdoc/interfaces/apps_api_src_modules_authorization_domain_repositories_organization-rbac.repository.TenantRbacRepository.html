    Interface TenantRbacRepository

    租户 RBAC 仓储端口（domain-owned · module-rbac-dynamic-roles §2.2/§2.3）。

    Remarks

    新宪（丙裁）：DB 是授权事实 SSOT——本端口是角色/授权读写的唯一通道：

    • 读侧供 checker 投影（findGrants · S2）与存在性校验（listRoles · S3 DTO 改形）；
    • 写侧供管理门面（create/rename/delete/grant/revoke · S3），每次变更同通道落审计行（甲裁）。 返回码用字面量 union（不借 HTTP 异常表达领域事实·应用层负责转译）；conditions 形状 校验在 domain 策略纯函数（policies/rbac.policy.ts），适配器写前必过闸。

    换轴注记（global-role-membership-tenantization 切片 C·承 global-tenant-organization-rehierarchy 片三 K5）： 角色目录与授权 grant 行均塔至纯租级——主轴 {tenantId, key}·tenant_role 无 organizationId 列 （unique (tenantId,key)·tenantId NOT NULL）；grant 行不再有组织收窄维（原 D1 tenant_role_grant.organizationId 已推翻·本切片 DROP 该列），findGrants 直取本角色全部行作适用集（跨 org 通配）。CRUD 不再需活动组织入参—— 审计改按租户盖章（tenant_role_audit.organizationId 降 nullable·留 NULL）。org 仅存数据分组（非授权轴）。
