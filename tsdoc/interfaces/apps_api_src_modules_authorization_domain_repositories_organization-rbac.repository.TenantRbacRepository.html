    Interface TenantRbacRepository

    租户 RBAC 仓储端口（domain-owned · module-rbac-dynamic-roles §2.2/§2.3）。

    Remarks

    新宪（丙裁）：DB 是授权事实 SSOT——本端口是角色/授权读写的唯一通道：

    • 读侧供 checker 投影（findGrants · S2）与存在性校验（listRoles · S3 DTO 改形）；
    • 写侧供管理门面（create/rename/delete/grant/revoke · S3），每次变更同通道落审计行（甲裁）。 返回码用字面量 union（不借 HTTP 异常表达领域事实·应用层负责转译）；conditions 形状 校验在 domain 策略纯函数（policies/rbac.policy.ts），适配器写前必过闸。

    换轴注记（global-tenant-organization-rehierarchy 片三 K5·第三次复裁切片 2 追平）：角色目录仍 塌缩至租级——主轴 {tenantId, key}·tenant_role 无 organizationId 列（unique (tenantId,key)·tenantId NOT NULL）； 但授权 grant 行可依组织收窄（tenant_role_grant.organizationId·NULL=租级通配跨 org·非 NULL=仅该 org 生效· D1）——本端口 findGrants 按活动 org 取「NULL ∪ 本 org」适用集·grant 写侧携可选 org scope。CRUD 的 organizationId 参仍兼 tenant_role_audit 归属盖章（活动组织缺位仍 fail-closed 拒写）。片二 K4 曾保数据 RENAME organization_role*→tenant_role*。
