    Interface TenantInvitationManager

    租级邀请管理端口（切片 D·organizations 租级邀请门面经本端口消费·写侧落 authorization 自有 tenant_invitation）。

    Remarks

    属主纪律：tenant_invitation 属 authorization（table-ownership），写适配器居 authorization 基础设施， organizations 门面经本 published port 相遇（沿 TENANT_MEMBERSHIP_MANAGER 同构）。 替代 BA org 维 invitation（invite-member/accept-invitation/cancel-invitation 内置面）· 接受入租的成员落行 + 席位卡点由门面组合 TENANT_MEMBERSHIP_MANAGER 与配额服务完成 （本端口只管邀请行本身的状态迁移·不跨上下文数席位）。
