    Interface StorageProvider

    存储提供方端口（出站网关·domain 拥有接口、infrastructure 提供实现）。

    Remarks

    原居 providers/storage.interface.ts，随分层对齐下沉至 domain/ports： 领域只依赖本接口，具体通道（s3/alioss/tencentcos）由 StorageModule.register() 依配置装配、StorageService 依 storage.provider 选择。零框架依赖（仅 node 流类型）。

    }
