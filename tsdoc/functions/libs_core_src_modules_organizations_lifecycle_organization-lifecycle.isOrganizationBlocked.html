    • isOrganizationBlocked(status: OrganizationStatus | undefined): boolean

      拦截判定（S4 中间件失能卡点·deny-list 语义）：仅显式处于失能态时拦截。

      Parameters

      • status: OrganizationStatus | undefined

        待判定的生命周期状态（可为 undefined）

      Returns boolean

      命中失能态返回 true；否则 false

      Remarks

      仅 pending_approval / suspended / deleted 时拦截。无状态记录 → 不拦 （兼容存量/seeded 无状态记录 org·避免锁定既有 dev 租户）。新申请经申请端点显式打 pending_approval → 天然失能，FR-1 闭环不受存量影响。
