    Function mergePredicatesWithOr

    • mergePredicatesWithOr(
          rowPredicates: readonly Record<string, unknown>[],
      ): Record<string, unknown> | undefined

      多 grant 行合并（人裁②·$or 并语义·与 CASL check 级并语义同解）。

      Parameters

      • rowPredicates: readonly Record<string, unknown>[]

        各 grant 行已译出的 where 片段（只读）

      Returns Record<string, unknown> | undefined

      合并后的谓词；空数组返回 undefined（调用点归空集）

      Remarks

      • 传入各行为已判定带 conditions 的行译词（调用点已筛掉 conditions=null 的类型级行·那些行 令调用点直接返回 null 全量，不进此函数）；
      • 空数组 = 无任何匹配行 ⇒ 返回 undefined，由调用点归空集谓词（fail-closed）；
      • 单行 = 直接返回该译词（省一层 $or）；
      • 多行 = { $or: [row1, row2, ...] }（Mikro 顶层布尔微语法）。
