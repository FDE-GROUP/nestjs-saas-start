    Function uuidv7

    • uuidv7(): string

      生成 UUIDv7（RFC 9562 §4.2.3）——应用生成 id 的唯一时间序形态。

      Returns string

      定宽小写 hex 的 UUIDv7 串

      Remarks

      module-es-first-real-consumer 附带机制统一：人裁 2026-10-17「时间戳在高位、按字节排序≈按时间排序」。

      布局：unix_ts_ms(48bit 大端) | ver=7(4bit) | rand_a(12bit) | variant=10(2bit) | rand_b(62bit)。 同毫秒内以随机位去重（RFC 允许·非严格单调计数）；跨毫秒按字典序≈时间序，可直接作 「最新行」排序键（免 createdAt tiebreaker）。

      运行核实证：Node 22 无原生 crypto.v7id（Node 24+ 才有），故零依赖手写；升级基线后可切换原生。
