    Function buildStorageKey

    • buildStorageKey(filename: string, now: Date, id: string): string

      对象键命名规则纯函数（真实领域策略：全通道统一 YYYY/MM/DD/<id><ext>）。

      Parameters

      • filename: string

        原始文件名（取扩展名用）。

      • now: Date

        键日期前缀的基准时间。

      • id: string

        调用方注入的唯一 id。

      Returns string

      规范对象键串。

      Remarks

      从 BaseStorageProvider.generateKey 提取——所有存储通道一致采用 YYYY/MM/DD/<id><ext>。id（uuid）与 now（时间）由调用方注入， 使本函数确定、可测、零外部依赖（不引 node:path/uuid）。
