    Function governedTenantTransition

    • governedTenantTransition(
          deps: GovernedTenantTransitionDeps,
          input: GovernedTenantTransitionInput,
      ): Promise<TenantGovernanceResult | null>

      租户治理迁移共用用例（rehierarchy 片一 治理台改锚 tenant）：suspend/resume 两 handler 的样板收敛单点。

      Parameters

      • deps: GovernedTenantTransitionDeps

        最小依赖面（状态服务 + 审计服务）。

      • input: GovernedTenantTransitionInput

        迁移入参。

      Returns Promise<TenantGovernanceResult | null>

      迁移后租户治理回执；租户查无为 null。

      Remarks

      语义逐字对齐旧 governedOrganizationTransition，惟锚从 organizationId 换 tenantId（companion org 不再误判 tenantExists(orgId)=false → 404）：

      • not-found → null（控制层转 404）；
      • illegal → 结构化审计（error: 'illegal_transition'）+ 409 ORG_ILLEGAL_TRANSITION；
      • ok → 结构化审计（from/to）+ 返回 {tenantId, status}。

      Throws

      租户生命周期迁移非法时。
