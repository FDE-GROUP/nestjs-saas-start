    Class TenantIsolationService

    当前请求租户作用域的读取器（ALS 支撑·单例免请求作用域化）。

    Remarks

    Accessor for the current request's tenant scope. Backed by AsyncLocalStorage so a singleton can read the per-request store without request-scoping every consumer (global-tenancy §9.3 / FR-2).

    S0 only exposes read access; the fail-closed enforcement guard (FR-5) lands in S2.
