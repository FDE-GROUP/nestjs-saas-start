    Class PlatformOrganizationsController

    平台操作员治理切片的 HTTP 控制器（多租户 S5 · FR-6/FR-11①/FR-13）。

    Remarks

    Platform operator governance slice (global-tenancy S5 · FR-6/FR-11①/FR-13).

    Every route is gated by PlatformOperatorGuard (the sole cross-tenant authority — the unique platform operator, DB email matches platform.operatorEmail, fail-closed). These handlers read/write WITHOUT a tenant scope on purpose: platform-level governance spans all tenants (FR-11①), so they deliberately never bind TenantIsolationGuard.

    Lifecycle transitions route through OrganizationStatusService.transition (single choke-point on the organization.status column — restored onto the BA shared table by governance-lifecycle-consolidation slice B, the former tenant side table being DROPped; §9.4 state machine): suspend (active→suspended), resume (suspended→active), delete (soft→deleted terminal). Each success/failure emits a structured audit line (FR-6).
