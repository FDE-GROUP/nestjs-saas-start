    Class PaymentController

    支付通道 HTTP 控制器：状态/客户/结账/退款/Webhook 端点，委托 PaymentService。

    Remarks

    非 webhook 属用户级（Stripe customer/checkout·不经租户仓储）→ 类级豁免租户墙（仍需会话）； webhook 方法级 @Public 自动兼豁免会话+租户墙。
