    Class OrganizationsOrgAdminController

    租户成员/邀请管理门面（module-rbac-casl §2.3.1·甲裁严格拆）。

    Remarks

    新宪落点：授权裁决 = @Can + CASL（authorization-rules 单源·经 AuthorizationGuard 判定）， 数据操作 = BA auth.api.* 服务端直调（认证·membership 数据域，不经被封堵的 BA 内置 org HTTP 面）。BA 服务端调用仍过其 membership/数据校验与 seats 配额 hook—— 门面是「授权在我、数据在 BA」的收口点，不是重实现。

    租户作用域路由：不豁免（S11 全局墙 fail-closed），guard 组合沿用 workspaces 先例。
