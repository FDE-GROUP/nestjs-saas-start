    Class OrganizationsOrgAdminController

    租户成员/邀请管理门面（global-role-membership-tenantization 切片 D·租级化）。

    Remarks

    新宪落点：授权裁决 = @Can + CASL（authorization-rules 单源·经 AuthorizationGuard 判定）； 数据操作 = 自有租级 SSOT（tenant_membership/tenant_role_assignment/tenant_invitation）经 TenantMemberFacadeService 编排——替代此前 BA auth.api.* org 维 passthrough （成员/邀请整轴上收租户维·org 降为纯数据分组）。角色可挂载校验、last-owner / self-removal 守卫、 席位卡点均在门面/领域侧重建（fail-closed·不再依赖 BA 内置数据守卫）。

    租户作用域路由：不豁免（S11 全局墙 fail-closed），guard 组合沿用 workspaces 先例。
