    Class PaymentService

    支付门面（application 编排层）：依 payment.provider 选择已注册的 PaymentProvider。

    Remarks

    采用懒解析——构造期不校验，避免未配任何通道时炸启动（NFR-2 未配即降级）； 仅在实际调用支付操作时，若无可用通道才抛 ServiceUnavailableException。 分层对齐后：通道选择/降级裁决与 Money 值对象下沉 domain，本层只编排并委托端口。
