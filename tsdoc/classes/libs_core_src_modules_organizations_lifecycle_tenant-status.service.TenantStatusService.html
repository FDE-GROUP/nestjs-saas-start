    Class TenantStatusService

    租户生命周期状态读写唯一卡点（global-tenant-organization-rehierarchy 切片 E-F 治理换轴·FR-1）。

    Remarks

    复裁定：治理准入态上移归位 tenant.status（本服务经 TenantStatusService 是唯一读写卡点， 禁散点手搓对象）。合法迁移成功后经 DOMAIN_EVENT_PUBLISHER 产出 OrganizationStatusTransitionedEvent（其 eventType=tenant.status.transitioned/ aggregateType=tenant 早已按租户命名·aggregateId=tenantId·消费侧 Odoo saga + 订阅联动据此驱动）。 关键段（写回 + 发布）包入 UNIT_OF_WORK（outbox 下域行与事件行同事务原子）。not-found/illegal 零分支绝不发事件。

    organization.status 经片二 K1 语义收口为组织自有轻量态（canUseOdoo 读·无独立读写服务），治理 生命周期权威态走本服务（TenantStatusService），两不相混。
