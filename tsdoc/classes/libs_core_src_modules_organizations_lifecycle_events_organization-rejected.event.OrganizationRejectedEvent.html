    Class OrganizationRejectedEvent

    平台经营者驳回 pending 租户申请（reject 硬删路径成功）时产出的事件。

    Remarks

    Raised when a platform operator rejects a pending tenant application (reject 硬删路径成功)。eventType tenant.rejected, eventVersion 1。

    驳回是「删除事实」而非状态迁移，故独立事件名、不复用 transitioned。 org 行被物理删除后，本事件是该租户「存在过并被驳回」的唯一耐久痕迹 （影子追加体系里「行没了、事件还在」的入口，plan §1）。 PII 边界：payload 只证明「何人何时驳回何 orgId」，不携 name/slug—— 驳回即应抹掉申请内容。aggregateType 取 tenant 与 tenant.transitioned 同流。
