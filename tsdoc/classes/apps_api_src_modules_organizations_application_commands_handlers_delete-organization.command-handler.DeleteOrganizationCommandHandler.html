    Class DeleteOrganizationCommandHandler

    软删租户 handler（FR-6·NFR-6·平台级）：迁至 deleted 终态（§9.4），经 TenantStatusService.transition(tenantId) 写回 tenant.status（rehierarchy E-F 治理换轴归位）。

    Remarks

    治理台改锚 tenant（rehierarchy 片一）：软删作用于租户准入态——封禁整个租户（其下所有组织随中间件 deny-list 失能）。 中间件 deny-list 即时失能。已 deleted 再删 → 非法迁移 409；不存在 → null（404）。落结构化审计。
