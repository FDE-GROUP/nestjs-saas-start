    Class TenantRbacAdminService

    角色/授权管理门面应用服务（module-rbac-dynamic-roles §2.5/§2.6·S3）。

    Remarks

    职责边界（授权在我·事实入 DB）：

    • 从 ALS 取活动租户（主轴 requireActiveTenantId·fail-closed）与操作者（userId·审计 actorId，缺省 null） （X7 切片 C：授权整轴上收租级·角色/授权 CRUD 不再需活动组织盖章·审计按租户留痕）；
    • 委派 TenantRbacRepository（授权事实 SSOT 的唯一读写通道·写侧先过 domain 策略闸并同通道落审计行）；
    • 将端口返回的领域结果码转译为 HTTP 语义（领域不借异常表达事实，转译归应用层）；
    • 写成功后失效本租户投影缓存（PermissionInvalidator·热改即生效·读写分治端口）。

    管理职权本身由 controller @Can(<动作>, 'Role' | 'RoleGrant') + CASL 守卫裁决（授权面）， 本服务不复权限判定（禁散点特判）；自定义角色对成员的挂载存在性校验见 isRoleAssignable。
