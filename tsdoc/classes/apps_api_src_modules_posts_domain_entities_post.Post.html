    Class Post

    posts 上下文的充血领域实体（Clean Architecture 锥体 Entities 层在本仓的首个物化样板）。

    Remarks

    与 infrastructure/entities/post.entity.ts 的物理数据实体（MikroORM defineEntity）严格分离： 本类零框架依赖（不 import @nestjs/*/@mikro-orm/*/HTTP/其他上下文·守 layer 依赖表 domain/ 行）， 承载不可变状态 + 构造期不变量 + 纯转移函数（返回新实例·FC 口径·architecture「投影镜射教义」）； 二者由仓储适配器经 infrastructure/repositories/post-mapping.ts 的纯 fromRow mapper 复原映射。

    两阶段构造：Post.draft 新建写意图（业务字段·经不变量校验·id/租户/时间戳为 null）； Post.restore 从持久层复原（含技术字段·不重复校验）。仓储 create/findById/list 一律返回 restore 后的完整实例，故到传输投影 PostReadModel 的映射只发生在完整实例上（领域实体绝不越界进 api/）。
