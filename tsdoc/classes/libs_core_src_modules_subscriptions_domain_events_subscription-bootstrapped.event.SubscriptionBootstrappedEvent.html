    Class SubscriptionBootstrappedEvent

    R4b bootstrap 脚本为每条存量 organization_subscription 行产出的事件（ES R4 第二上下文推广）。

    Remarks

    Raised by the R4b bootstrap script for each pre-existing organization_subscription row （ES R4 第二上下文推广 · module-es-r4-second-context-subscriptions·裁ⓒ·沿 tenants bootstrapped 律）。 eventType subscription.bootstrapped, eventVersion 1, aggregateType subscription。

    语义：存量流起点快照——全流回放采「最后快照重启」（覆盖此前一切·不重排历史·同 tenants R1b）； version 从流现有 max+1 续位·幂等律=流内已含本事件则跳过。aggregateId=订阅行 id（裁ⓐ甲）。

    PII 边界：payload 仅治理态 + opaque 计划码·无 subject PII（表列=id/organizationId/plan/status/limits/period/provider refs）。
