    Class TenantMemberFacadeService

    租级成员/邀请管理门面服务（global-role-membership-tenantization 切片 D·organizations 核心域本体）。

    Remarks

    替代此前 OrganizationsOrgAdminController 的 BA passthrough：成员/角色/邀请数据操作不再透传 BA org 维内置面，而是编排 authorization 自有租级 SSOT（经 published port TENANT_MEMBERSHIP_MANAGER / TENANT_INVITATION_MANAGER 相遇·写侧落 authorization owned 表）。角色可挂载判定复用 ROLE_ASSIGNABILITY_READER（authorization published port·A5 接缝同律）。

    守卫在门面重建（fail-closed）：

    • 角色不可挂载 → 400（ROLE_NOT_FOUND）；
    • last-owner / self-removal → 403（降级/移除唯一 owner·管理员自移）；
    • 接受邀请 → 受邀邮箱匹配（防他人消费邀请）+ 席位卡点 QuotaService.checkSeats（超限 402· 替代退役的 BA seats-quota.hook 于本入租时点显式裁决）。

    租户轴一律 TenantIsolationService.requireActiveTenantId（隔离主轴·fail-closed 403）； 跨租硬地板由 manager 的 where{tenantId} 锚定·门面不另起炉灶。
