    Class TenantsController

    租户目录端点（global-tenant-organization-rehierarchy 切片 E-F·FR-11 用户级读面）。

    Remarks

    列当前用户可见的租户（顶层）及其下组织（二级），供前端双层切换器。跨租可见（成员资格归组· 此刻尚无单一 active 租户可言），故类级 @TenantIsolationExempt() 旁路租户墙、逐路由 SessionGuard 保会话必需；可见面由仓储以 userId 收敛（成员资格归属），非独立隔离闸。只读——审批/切换仍走 organizations 准入面（saga 已随换轴归位租户态），本面不重复其写职责。例外（切片 4·D7）：新增 PUT /tenants/active——它不写租户生命周期态，只写当前会话的租级激活位（session-scoped）。

    setActiveTenant

    • setActiveTenant(
          user: SessionUser,
          dto: { tenantId: string },
      ): Promise<{ tenantId: string }>

      设置当前会话的活动租户（第三次层级复裁 切片 4·D7 租激活解绑）。

      Parameters

      • user: SessionUser

        会话用户（携 sessionId·写坐标可信）。

      • dto: { tenantId: string }

        目标 tenantId。

      Returns Promise<{ tenantId: string }>

      已激活租户回执；写行查无 → 401。

      Remarks

      选租不依赖先选活动组织：写入会话 activeTenantId 后，后续租级端点（计费/席位/目录）即可在无 活动 org 下经中间件绑定租上下文抵达。handler 先校目标租成员资格（非成员 403·fail-closed），再经 属主端口写会话真列。sessionId 由 SessionGuard 从已验签会话挂上；缺失 → 400。
